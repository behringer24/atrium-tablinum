# Contributing

Thank you for your interest in Atrium Tablinum. Bug fixes, documentation fixes, tests and small improvements are welcome.

- **Open an issue first** for anything bigger than a fix, so that you do not spend time on something that cannot be accepted. The maintainer decides what the project contains and may decline a contribution without giving a reason.
- **Accept the [Contributor License Agreement](CLA.md)** before your first contribution is merged.
- **Keep changes small and focused**, with tests where behaviour changes. `go vet ./...` and `go test ./...` must pass; the database tests need a Postgres with pgvector (see the README).
- **English only** in code, comments, documentation and commit messages.
- **Security problems** go to the maintainer privately, not into a public issue.
